# 正心OCR 帮助

正心OCR 是本地文献识别工具。Windows 版统一使用通用安装程序，首次准备需要联网，准备完成后可离线识别。

## 首次启动
程序自动检查 Python、识别依赖和模型，缺少时自动下载并安装到应用专用目录。请保持网络连接，准备日志会显示当前步骤。
准备失败后可点击“检查 / 修复环境”重试；通过自检的模式仍可使用。不会向系统 Python 安装依赖。

<details>
<summary>环境目录与故障排查</summary>
环境、模型、日志和任务记录位于 %LOCALAPPDATA%\ZhengxinOCR。
准备日志为 logs\prepare.log；任务日志为 jobs\任务编号\worker.log。
每个任务在所选输出目录中建立独立子目录，防止不同文件的结果混用。
当前候选版使用 CPU 推理。古籍正本只有在本机模型识别自检通过后才启用。GPU 加速尚未完成 Windows 实机验证。
请先确认网络、剩余磁盘空间和目录权限；修复时将建立新的环境，通过检查后再切换。
</details>

## 选择文件和模式
输入支持 PDF、PNG、JPEG 和 TIFF。点击路径右侧放大镜选择输入文件与输出目录。
普通扫描：用于规整印刷文献。适用的纯文字页面直接提取可见文字，扫描、混排、隐藏文字层和异常映射页面继续 OCR。
复杂排版：用于多栏、表格、公式和图文混排。
古籍正本：用于竖排、夹注、生僻字等文献。本机未通过自检时不启用。

## 查看结果
程序逐页处理并保留已完成结果。“渲染页”可能少于“识别页”，因为原生文字直接提取无需生成页面图片。
点击“显示结果”打开任务输出目录；其中包含逐页原始结果及可提取时合并的 document.txt 或 document.md。performance.json 记录逐页路径和耗时。
古籍、异体字、夹注和残损文字应对照原始页面校勘。

## 关闭与取消
识别中退出可选择“继续识别并退出”“取消任务并退出”或“返回”。继续识别时任务留在本机后台，重新打开应用可接回。
取消将终止该任务的工作进程并保留已完成结果。环境准备过程中请等待当前准备结束后退出。
