# 正心OCR 通用安装版：界面验收

## 设计依据

- 参考风格：浅色界面、低对比度层次；根据实机反馈移除三块圆角分组底框。
- 底色：`#F3F4F8`。
- 输入框边框：`#C9C9AD`。
- 按钮：`#CEBA7B`。
- 主要文字：`#2A3F52`。
- 次要文字：`#556775`。

## 响应式规则

- 窗口最小尺寸为 900 × 650，避免关键控件被压缩到不可用。
- 按钮保持固定宽度；右侧“选择”按钮固定贴右。
- 输入框和进度条只沿水平方向伸缩。
- 顶部表单固定在窗口上方，日志区独立随窗口高度伸缩。
- 安装区、文件区和操作区不使用分组底框，避免界面出现多余层级。
- 日志区域使用直角边框，并独立随窗口高度伸缩。

## 实际验证

- [x] 900 × 650 最小窗口：按钮未拉长、未压缩、未重叠、未消失。
- [x] 最大化窗口：输入框、进度条和日志区正常扩展。
- [x] 三个圆角分组底框已移除，顶部各区域无覆盖。
- [x] 日志框四角为直角。
- [x] 标题、说明、状态、日志采用指定文字层级配色。
- [x] 新图标已出现在应用包及窗口标题栏。
- [x] 图标底图已改为全幅不透明，并由 Xcode 编译为现代 `Assets.car` 与兼容用 `AppIcon.icns`。
- [x] 输入文件、输出目录和识别模式三行的标签、控件及说明统一垂直居中。
- [x] 古籍、复杂排版、普通扫描三种模式均显示各自说明。
- [x] 输入框只绘制一层背景，不再出现文字后的独立白色底条。
- [x] 输入文字和占位文字距左右边缘各 10px，仍保持标准可编辑文本框行为。

## 尚待实机确认

- Intel Mac 上的字体抗锯齿和不同缩放比例显示。
- 深色模式下仍保持本应用指定的浅色主题，不自动切换为深色。
